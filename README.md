# Interactive-Dashboard-using-Excel

### Interactive Sales Dashboard using Excel

An interactive data analytics dashboard built entirely in Microsoft Excel to track sales performance, target achievements, and executive efficiency across multiple regions. This project demonstrates advanced data transformation, pivot tables, dynamic charting, and user-friendly dashboard design tailored for business decision-making. 

### 📊 Live Dashboard Preview

Tip for recruiters: If you wish to interact with the slicers and dynamic formulas firsthand, please download the Interactive Dashboard using Excel.xlsx file above. 

### 🚀 Key Features & Functionality

* *Dynamic Slicers:* Allows stakeholders to instantly filter all visual charts by Region, Sales Executive, or Target Timeline.
* *Conditional KPI Blocks:* Highlights whether teams are "Away from Target" or "Target Met" using automated logic.
* *Automated Data Pipeline:* Built using structured Excel tables so new monthly sales data refreshes the dashboard instantly with one click.

### 🛠️ Tech Stack & Excel Functions Used

* *Data Visualization:* Pivot Charts (Bar, Line, and Pie charts), Custom KPI Cards, Interactive Slicers.
* *Advanced Formulas:* IF, AND, VLOOKUP/XLOOKUP, SUMIFS, and Logical Boolean strings (TRUE/FALSE validation arrays).
* *Data Modeling:* Power Query (for data cleaning and joining) and Pivot Tables for rapid multi-dimensional aggregation.

### 📈 Core Insights Discovered

1. *Top Performers:* Identified the specific Sales Executives consistently meeting or exceeding their target matrices.
2. *Regional Variance:* Uncovered significant gaps between target expectations and actual total sales across different operational zones.
3. *Productivity Trajectory:* Isolated timelines where sales velocity dipped, indicating a need for targeted marketing interventions.

### 📂 Repository Structure

* /Interactive Dashboard using Excel.xlsx — The complete interactive workbook containing the raw data, calculations, and the visual dashboard.
* /Interactive Dashboard using Excel.csv — The flattened, machine-readable dataset for open tracking and version transparency.
